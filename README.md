# לקחתי? 💊

אפליקציית אנדרואיד קטנה לסימון תרופות: מוסיפים תרופות ושעות, מסמנים "לקחתי", ומקבלים תזכורת.

- מסך יום: כל המנות של היום, לחיצה מסמנת / מבטלת. אפשר לעבור לימים קודמים ולתקן.
- התראה בשעה של כל מנה, עם כפתור "✓ לקחתי" ישר מההתראה (לא מגיעה אם כבר סימנת).
- לוח שנה: ורוד = הכל נלקח, ורוד בהיר = חלק, אפור = כלום. לחיצה על יום פותחת אותו.
- רצף ימים מלאים 🔥.
- הכל נשמר רק בטלפון.
